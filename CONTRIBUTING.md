# Contributions

ACP is an abandoned experiment. No maintainer response time or future roadmap is promised.

If you study or adapt it, start with the README and security boundaries. Keep changes small and test them using only disposable synthetic data. Describe exactly what was tested and what was not. Do not send credentials, private project contents, database files or virtual-machine images in issues or pull requests.

Do not interpret a green unit test run as production approval, live-provider certification or a new physical-isolation result. Re-validating those claims is separate work.
